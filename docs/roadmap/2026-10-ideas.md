# Ideas analysis for the library, October 2026

Date: 2026-10-18. The full analysis, which covers agentprose Cloud too, lives in the (private) Cloud repo. This is the library part: what goes into the open-source library, and why.

**Placement rule.** The library gets everything that works on a static site with no backend: tool behaviour, data the site publishes itself, the CLI, docs and tests. It stays self-contained, privacy-first, and silent until an agent calls a tool. Hosted conveniences (dashboards, analytics, editing without a redeploy) belong to a service, and a paid service never takes away what the library can do on its own.

Sources of ideas: OpenHermit (agent tools for actions) and webmcpify (an agent skill for adding WebMCP to apps). Both are MIT-licensed. We borrowed ideas only, no code.

| Idea | Decision | Notes |
|---|---|---|
| Owner notes for AI agents (`agentNotes`) | Done (0.1.3) | Page config, `agentprose.json` (`agentprose build --site`) or a Cloud. Cleaned, capped, labelled as preferences. |
| Contact and booking details (`contact`, `get_contact_info`) | Done (0.1.3) | Registered only when the page declares contact details or uses a Cloud. |
| `<link rel="agentprose-index">` | Documented (0.1.3) | The script already read it; now the docs and the CLI say so. Injecting it with JavaScript was rejected: crawlers do not run scripts. |
| Agent skill for coding agents (`skills/agentprose/SKILL.md`) | Done (0.1.3) | `npx skills add webmaxru/agentprose` |
| Tool-result contract test | Done (0.1.3) | Every built-in tool, any input: an object, never `null`/`undefined`, never throws. |
| Inspector: object or JSON-string input, string or value results | Done (0.1.3) | One retry with a string on `TypeError`; safe because the tools are read-only. |
| Dated browser evidence | Done (0.1.3) | docs/browser-support.md |
| Forward the execution `AbortSignal` to fetches | Later | Only Chrome Beta passes a signal; costs bytes in the core budget. |
| `/.well-known/webmcp` manifest from `agentprose build` | Later | A non-normative convention with no consumer to test against yet. |
| Count agent-submitted forms (`SubmitEvent.agentInvoked`) | Later | Experimental API; linking a read to a form on another page would need a stored visitor id, which the library will not keep. |
| Upgrade dev tooling (vitest, happy-dom, esbuild) | Later, own PR | `npm audit` flags dev-only packages; nothing ships to users (zero runtime dependencies). An esbuild bump changes bundle bytes, so it needs its own size check. |

**Size budget.** Owner details and `get_contact_info` add about 700 B gzipped to core + engine. The budget moved from 16,640 B to 17,408 B (+768 B), and the core stays under 10,240 B.
